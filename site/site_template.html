03 / Method

  1. Step 1

    Same app everywhere

    Three copies of one web server on every orchestrator, on the same PC, one tool at a time.

  2. Step 2

    Load it, then break it

    5,000 and 20,000 requests, then one copy is killed while traffic keeps coming. Every test runs three times.

  3. Step 3

    Score what matters to you

    Your answers weight the measured numbers and documented features, and the advisor explains its pick. Anything not measured counts as average, so it never helps a tool.

04 / Run it on your computer

Step-by-step guide. Which container tool is best for you?

Same advisor as this page, in Python. Steps 1 to 4 give you advice in one minute. Steps 5 to 8 test your own computer, so the advice fits your machine.

Quick advice · 1 minTest my computer · 1 hour

Part A · Quick advice

Needs · Python 3 only
01

Open your terminal and check Python

The advisor only needs Python 3.8 or newer. Nothing else to install. On Windows, type python instead of python3.

Windows · Start → PowerShellMac · ⌘ Space → TerminalLinux · Ctrl Alt T
Terminal
$ python3 --version
Python 3.12.3
02

Download KubeChaos from GitHub

This copies the tool and our measured results to your computer. No git? Click Download ZIP on the GitHub page, unzip it, and open the folder in your terminal.

GitHub · github.com/DKhadka319/kubechaos
Terminal
$ git clone https://github.com/DKhadka319/kubechaos
$ cd kubechaos
03

Start the advisor and answer 6 questions

Type the number of your answer and press Enter. Press Enter alone to keep the default. Same six questions as this page.

Takes about 1 minute
Terminal
$ python3 advisor.py

What will you run?
  1. A website or API with many users
  2. Apps on small edge or IoT devices
  3. Learning, testing or a class project
  Your choice (number) [1]: 2

Part B · Custom advice for your machine

Want advice from your own numbers?

Needs · Docker · 8 GB RAM · Linux or Windows WSL2
05

Install Docker and the five tools

Install Docker Desktop first. On Windows, turn on WSL integration and use the Ubuntu terminal. Then run our setup script, which installs Kubernetes, K3s, MicroK8s and Nomad for you.

Windows · Ubuntu (WSL2)Linux
Ubuntu
# inside the kubechaos folder
$ bash setup.sh
Setup done. Close Ubuntu and open it again.
06

Run the crash and load tests on your computer

KubeChaos starts each tool one by one, deploys the same web app, sends traffic, then kills a copy on purpose and times the recovery. Leave it running.

Takes about 1 hour
